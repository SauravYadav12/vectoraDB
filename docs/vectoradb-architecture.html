Architecture Overview · Plain English

VectoraDB

A serverless database that behaves exactly like the widely-used PostgreSQL — with three superpowers on top: instant copies, a rewind button for your data, and continuous cloud backup — while everyday speed is never sacrificed.

No app changes Full-speed transactions Copies use almost no space Open source

How it fits together — read top to bottom: people and programs connect, the live database serves them fast, and its history is safely copied to the cloud.

What Makes It Special

Four capabilities, in plain language

⚡

Serverless & Standard

Your existing apps connect with zero changes. Computing power wakes up on demand and sleeps when idle.

Like a motion-sensor light — on when needed, off (and cheap) when not.
🌿

Instant Branching

Copy the entire database in seconds, using almost no extra space — a private, disposable sandbox for each AI agent, test, or feature.

Like “Duplicate” on a document — but for a whole database, instantly.
⏱️

Time Travel

Rewind the database to any moment in the past to undo a mistake or inspect exactly how things looked.

Like Undo and version history — for all of your data at once.
☁️

Never Lose Data

Every change is continuously copied to durable cloud storage in the background, without slowing anything down.

Like auto-save to the cloud — always on, never in the way.

How your data flows

  1. Connect: your app talks to VectoraDB exactly like a normal PostgreSQL database.
  2. Serve fast: everyday reads and writes happen at full speed on fast local storage.
  3. Protect in the background: every change streams to cloud storage — powering time-travel and instant recovery.
  4. Branch on demand: a full copy of the database is created in seconds whenever an agent or developer needs one.

Why it matters

  1. Move faster & safer: give every experiment its own copy, and undo mistakes with time-travel.
  2. Built for AI: each AI agent gets its own isolated database to work in — then it’s thrown away, cleanly.
  3. Lower cost & risk: copies and backups are cheap; the database you already trust (PostgreSQL) stays at the core.
Built on proven, open foundations: PostgreSQL (the database), ZFS (instant copies), and cloud object storage (durable history).  ·  Licensed open source.  ·  Working today: continuous backup, time-travel, and instant branching.  ·  Next: one-branch-per-AI-agent API.
